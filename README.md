# E-Commerce Sales & Customer Analytics

## 📊 Project Overview

An end-to-end e-commerce data analytics project using Excel, MySQL, SQL, and Power BI.

The project analyzes sales, profit, customers, products, regions, and customer segments to generate business insights.

## 🎯 Project Objectives

- Analyze total sales and profit
- Track monthly sales trends
- Compare regional performance
- Analyze product and category performance
- Identify top-selling products
- Analyze customer segments
- Perform customer revenue analysis using SQL
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies

- Microsoft Excel
- MySQL
- SQL
- Power BI
- DAX
- Power Query

## 📈 Power BI Dashboard

The dashboard includes:

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products by Sales
- Customer Segment Analysis
- Interactive Region and Category filters
